# 🌟 Featured Projects

## 🍔 Sentiment Analysis of McDonald's Customer Reviews

**NLP | Machine Learning | Python | Scikit-learn | TF-IDF | VADER**

A sentiment analysis project focused on understanding customer opinions from restaurant reviews.

* Processed and cleaned **22K+ customer reviews**
* Developed a sentiment labeling and validation workflow
* Explored **rating-based sentiment mapping**
* Compared multiple ML models including:

  * Logistic Regression
  * Linear SVM
  * Multinomial Naive Bayes
* Evaluated models using **Accuracy, Macro-F1 and Cohen/Fleiss agreement metrics**
* Built a Streamlit-based interface for analysis and visualization
* Containerized the application using **Docker**
